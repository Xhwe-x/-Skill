# 通用内容模板的使用

用户自有《投标v101.docx》是通用内容的主要来源，优先读取用户提供的原件，保留与本项目适用的内容深度及表达；本仓库不含原件。当前招标的章节、评分细目和实质要求优先，不能用模板替代逐项响应。

可按项目选用、展开并重组以下模块：项目理解；建设现状与需求；建设或服务原则；风险分析及对策；服务方案（包括进度控制、质量保障、后续服务）。每个模块要结合现状、责任主体、执行步骤、工作节点、形成成果、检查方法和异常处理写成可实施正文。依项目增补技术路线、实施、运维、安全、施工等招标要求的专门章节。

原件与已知信息不能证明项目或企业事实；不得套用历史项目名称、数量、人员、证书、承诺和执行时限。需要利用原模板具体文字时而原件不可取得，说明该限制，不虚称已读取或完整复用原文。
